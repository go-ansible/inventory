# inventory

Ansible-compatible inventory: INI/YAML parsers, groups, host/group vars, patterns.

Part of [go-ansible](https://github.com/go-ansible) — a pure-Go (CGO=0),
functional-parity port of [Ansible](https://www.ansible.com/).
